# FAKE_NEWS - Микросервис по созданию фейковых страниц новостного сайта.
## Установка
1. Клонировать репозиторий:
      ```bash
   git clone https://github.com/KinzyabaevVadim/FAKE_NEWS.git
2. Установить необходимые библиотеки:
      ```bash
   pip install -r requirements.txt
3. Запустить сервер:
      ```bash
   python app.py
После запуска сервера перейдите по локальному пути: [http://127.0.0.1:5000](http://127.0.0.1:5000). Откроется главная страница сайта.
### Пользование сайтом:
1. **Заголовок истории**: Напишите заголовок для вашей статьи.
2. **Краткое описание**: Добавьте описание статьи. (На самом деле можно писать сколько угодно, краткость не нужна...хехе)
3. **Фото для новости**: Вставьте фотографии, приложенные к статье (не более 5 штук).
4. **Имя журналиста**: Имя того самого журналиста написавшего эту фейковую статью
![chrome_cF5zwm9Bos](https://github.com/user-attachments/assets/9e4382ee-7927-471e-bd8c-2027e100fe1e)
5. **Редактирование новостного сайта**:
      - Наименование сайта
      - Рекламные баннеры (используйте широкий баннер для корректного отображения)
      - Дата написания статьи
      - "Читайте так же"
